# 常用网站识别支持

验证日期：2026-10-03。当前登记 45 个平台品牌、46 条平台规则（B 站另有 b23.tv 短链规则），覆盖下面的常用内容网站。登记表示可识别来源及常见内容路径，并尝试读取公开信息；不表示每个平台、每条链接均已完整实测。

未登记的普通网站也可以通过 Open Graph、Twitter 元数据、JSON-LD 和正文回退提取标题、作者、描述、封面及标签。

## 解析方式

- B 站、知乎、小红书、抖音、快手、YouTube、小宇宙、简书、微博增加页面初始数据解析，按内容 ID 选择当前条目，避免读取推荐内容。公众号读取正文元素和分享变量；GitHub 读取仓库拥有者和主题标签。
- CSDN、掘金、博客园、少数派等网站增加正文作者、标签、懒加载图片的选择规则。掘金忽略站点推广关键词，优先采用文章自己的标签或结构化标签。
- 其余平台主要使用通用元数据及可用的正文规则；目前没有逐站实现动态脚本解析，也没有逐站完成实网验证。
- 内容类型结合具体路径和页面声明判断；平台首页、作者主页不会仅因域名而被判成视频或音频。网易云音乐优先于网易新闻规则。
- 标签来自原页面标签、关键词或分享话题。没有标签时保持为空；不将缺失字段视为已经提取成功。

## 遇到限制时

验证码、登录页和已识别的错误页不会作为收藏内容，也不会替换原始链接。服务保留分享文字中可以读取的标题和话题，并提示补全。小红书等分享地址中的访问令牌予以保留，只有明确的追踪参数会被移除。

页面脚本只提取 JSON 或字符串，不执行；不会绕过验证码、登录或付费权限。网页请求支持 gzip、deflate、Brotli，传输大小与解压后大小均受限制。外部封面仍可能受防盗链或链接失效影响。
