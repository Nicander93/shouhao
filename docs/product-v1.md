# 初版产品范围

收好用于保存以后想看、想听或再次查找的内容。核心流程是：收集 → 识别与补全 → 收藏库 → 搜索/标签/状态 → 打开原内容。

## 收集

支持链接、速记、图片。链接允许粘贴 App 的分享文字，提取其中的 URL；读取标题、摘要、封面、来源与作者，区分视频、音频、文章、网页。读取不成功时保留链接，由用户手动补全。图片上传到自己的服务，不限于网址收藏。

## 使用

主界面是卡片收藏库，不增加推荐流。用标签组织内容，用待看/看过记录简单状态；星标标记想再次翻看的收藏。点击卡片查看、编辑；点击打开原内容由浏览器回到原网页或交由平台唤起 App。

## AI

AI 是可选整理工具，不是收藏前置条件。只基于标题、摘要和速记提出建议，用户采用后才改变字段；不自动生成未经读取的内容摘要。部署者配置模型服务，密钥保留在服务端。

## 本次实现选择

面向个人、自行部署、单用户。SQLite 和文件目录持久化，可由多个设备访问同一个服务。不引入多用户体系、复杂目录层级或平台账号集成。UI 以纸张感的简洁收藏卡片为主，少量手绘感细节，手机上保持单列阅读和顺手添加。

## 未来再决定

移动系统分享入口、图片 OCR、平台专用解析器、封面本地缓存、完整导入导出、离线与批量整理；依据实际使用反馈选择，不作为初版已完成能力。
